# Matemática Aplicada 1

Repositorio de actividades, ejercicios y evaluaciones del curso **Matemática Aplicada 1**. El material está desarrollado principalmente en notebooks de Jupyter utilizando Python.

## Contenidos

- Introducción a Python y resolución de problemas.
- Funciones y función lineal.
- Aplicaciones de funciones.
- Sucesiones.
- Matrices y aplicaciones de matrices.
- Guías, formularios, controles y evaluaciones.

## Requisitos

- Python 3.
- Jupyter Notebook o JupyterLab.

Para instalar Jupyter:

```bash
pip install jupyter
```

## Uso

1. Clona el repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Inicia Jupyter:

   ```bash
   jupyter notebook
   ```

4. Selecciona el notebook que quieras revisar y ejecuta sus celdas en orden.
